# Анализ продаж интернет-магазина (Online Retail)

Пет-проект аналитика данных: анализ выручки, сезонности, ассортимента и географии продаж.

## Цель проекта

Проанализировать данные интернет-магазина, выявить ключевые товары и страны, построить дашборд в Power BI для быстрого понимания состояния бизнеса. 
Стек: Python (Pandas), Power BI, Git.

## Основные выводы

- **Выручка:** выраженная сезонность, рост в ноябре 2011; декабрь исключён из анализа (неполный месяц).
- **Ассортимент:** доля топ‑10 товаров в выручке — 7,9%. Ядро ассортимента — недорогие ходовые товары (2–4 £). Один товар за 649 £ является выбросом и сильно искажает среднюю цену.
- **География:** Великобритания — основной рынок; за пределами UK выручка формируется в основном за счёт B2B‑клиентов (оптовых заказов).
- **Методология:** сервисные позиции (POSTAGE, DOT и др.) исключены из рейтинга товаров, но учтены в общей выручке.

## Структура проекта

- `notebooks/`: Jupyter Notebook с расчётами (Pandas, очистка данных, агрегации).
- `data_export/`: агрегированные CSV-таблицы для Power BI.
- `images/`: скриншот дашборда.
- `powerbi/`: файл дашборда Power BI (`sales_dashboard.pbix`) — не загружен в GitHub из‑за размера.
